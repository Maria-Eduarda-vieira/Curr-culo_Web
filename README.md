### 📌 Sobre a Atividade

Nesta atividade de Linguagem de Marcação, desenvolvi meu primeiro **Currículo / Portfólio Web** pessoal utilizando HTML5 puro. 

O projeto conta com navegação interna por âncoras (`#sobre`, `#projetos`, `#contato`), apresentação das minhas qualificações no curso técnico, tabela dinâmica organizando meus projetos desenvolvidos até o momento e um formulário completo para contato.

---

### 🛠️ Ferramentas Utilizadas

| Ferramenta | Aplicação no Projeto |
| :--- | :--- |
| **HTML5** | Estruturação da página, tabelas, formulário e links de navegação |
| **CSS (Inline)** | Personalização de cores do tema (tons terrosos e escuros) e estilos de tabelas |
| **Visual Studio Code** | Ambiente de desenvolvimento de código |

---

### 🎯 Conteúdo do Portfólio

| Seção | Recursos e Conteúdo | Tags Utilizadas |
| :--- | :--- | :--- |
| **Sobre Mim** | Apresentação pessoal, foto de perfil e lista de competências técnicas | `<img>`, `<ul>`, `<li>`, `<strong>`, `<em>` |
| **Meus Projetos** | Tabela organizando projetos (Semáforo Inteligente, Formulário PHP e Game Zone) | `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<td>`, `<a>` |
| **Contato** | Formulário funcional para envio de mensagens com diferentes tópicos | `<form>`, `<fieldset>`, `<input>`, `<select>`, `<textarea>` |

---

### 🚀 Objetivos Concluídos

- [x] Estruturar uma página web completa do zero utilizando tags semânticas do HTML5.
- [x] Aplicar teoria das cores diretamente nos atributos de estilo do documento.
- [x] Criar navegação interna por links âncora (`<nav>` e `id`).
- [x] Desenvolver uma tabela organizada para exibição de dados e links externos.
- [x] Construir um formulário de contato interativo com campos de seleção e caixa de texto.
